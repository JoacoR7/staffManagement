# Dashboard del restaurant
Aplicación frontend que permite el manejo sencillo del servidor utilizando llamadas HTTP. Fue desarrollada mediante la modificación de una plantilla preexistente. Es un componente del ecosistema de aplicaciones desarrolladas para el restaurant.

## Tecnologías utilizadas
- React
- Javascript
